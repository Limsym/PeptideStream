| 封装批量预测接口（对接生成模块）                | [] | 支持新序列自动评估                                  |

多指标评价非常适合此项目，并适宜作为独立研究方向来设计，甚至尝试用强化学习或贝叶斯优化来搜索最优序列组合。这是因为多目标优化能：

- 能进行精度更高的预测；
- 保留了维度信息，**支持更清晰的可视化、可解释性和后续优化**；
- 可设定阈值过滤，**实现早期淘汰低质量序列**
- 真实保留 trade-off 关系，**保持生物建模的可信性**，展现各预测项目的风险与机会；
- 不合成打分项，**避免预测生物信息的损失或过拟合**
- 能带来一个看起来聪明的打分以便下游使用；
